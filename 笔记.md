## 今日目标
跑通 CartPole 随机策略，并训练一个 PPO 模型。

## 踩过的坑
1. 把终端命令 `python -c "..."` 错写进了 `.py` 文件里。
2. 没有注意 PyCharm 的 `.venv` 虚拟环境，导致装好的包找不到。
3. `pip install` 没换源，试图从源码编译 `numpy` 导致失败，换成清华源后解决。
4. 训练时加了 `render_mode="human"`，导致训练卡死，删掉后正常。

## 成功代码
```python
import gymnasium as gym
from stable_baselines3 import PPO

env = gym.make("CartPole-v1", render_mode="human")
model = PPO.load("ppo_cartpole")
obs, info = env.reset()
while True:
    action, _ = model.predict(obs, deterministic=True)
    obs, reward, terminated, truncated, info = env.step(action)
    if terminated or truncated:
        obs, info = env.reset()
env.close()
```

```python
import gymnasium as gym     #导入强化学习标准环境库
from stable_baselines3 import PPO       #导入强化学习算法库POP算法

env = gym.make("CartPole-v1", render_mode="human")      #搭建环境；渲染模式：人类可见
model = PPO.load("ppo_cartpole")        #加载之前训练的模型
obs, info = env.reset()        #初始化
for _ in range(500):        #最多尝试500步
    action, _ = model.predict(obs)      #AI根据当前状态决定动作
    obs, reward, terminated, truncated, info = env.step(action)     #执行动作
    if terminated or truncated:
        break                           #只看AI玩一局

env.close()     #关闭环境
```

## 实验代码
```python
import gymnasium as gym
from stable_baselines3 import PPO
import numpy as np

env = gym.make("CartPole-v1", render_mode="human")
model = PPO.load("ppo_cartpole")

# 跑 10 局，统计得分
episode_rewards = []
for episode in range(10):
    obs, info = env.reset()
    total_steps = 0
    done = False

    while not done:
        action, _ = model.predict(obs, deterministic=True)
        obs, reward, terminated, truncated, info = env.step(action)
        total_steps += 1
        done = terminated or truncated

    episode_rewards.append(total_steps)
    print(f"第 {episode + 1} 局，坚持了 {total_steps} 步")

env.close()

# 计算平均分
average_steps = np.mean(episode_rewards)
print(f"\n10局平均坚持步数: {average_steps:.2f} 步")
```
